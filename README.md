# AI Career Placement Platform

An AI-powered career and placement assistant designed to help students with placement preparation, resume analysis, company eligibility, job-description matching, skill-gap analysis, and interview preparation.

## Overview

The AI Career Placement Platform combines a React frontend, FastAPI backend, and Microsoft Azure AI Foundry to provide students with an AI-based placement assistant.

The platform is designed to help students:

- Manage their placement profile
- Upload and analyze resumes
- Calculate company eligibility
- Analyze job descriptions
- Match resumes with job descriptions
- Identify skill gaps
- Find relevant learning resources
- Prepare for interviews
- Practice placement-related questions
